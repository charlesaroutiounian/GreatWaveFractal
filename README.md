# The Great Wave Fractal
### 神奈川沖浪裏 — *Under the Wave off Kanagawa*

---

## The Painting

Katsushika Hokusai's woodblock print *The Great Wave off Kanagawa* (c. 1831) is one of the most recognisable images in the world. What makes it visually striking — and mathematically interesting — is the shape of the wave itself: a towering arc whose curling crest breaks into smaller arcs, which in turn break into smaller ones still, down to the finest spray of foam. The whole scene is built from **self-similar curved forms nested inside each other**.

That self-similarity is not an accident of Hokusai's hand. It is the same geometric property that Benoît Mandelbrot, more than a century later, would name **fractal**.

---

## Mandelbrot and Fractals

In 1975 Benoît Mandelbrot coined the term *fractal* (from Latin *fractus*, broken) to describe shapes that:

1. **Repeat at every scale** — zoom in and the detail looks like the whole.  
2. **Have non-integer dimension** — they are "more than a line, less than a plane".  
3. **Are generated by a simple recursive rule** applied infinitely.

The most famous example is the Mandelbrot set, defined by iterating *z → z² + c* in the complex plane. But fractals are not confined to abstract mathematics — Hokusai's wave, coastlines, trees, snowflakes, and lung bronchioles are all natural fractals.

## The Arc Fractal — How It Works

This Swift playground constructs a fractal wave from **arc segments** (portions of circles), mirroring the curved, self-similar structure of Hokusai's wave.

### The Primitive: an Arc Segment

Any point on a circle of radius *r* centred at *(cx, cy)* is given by the **parametric circle equation**:

```
P(θ) = ( cx + r·cos(θ),  cy + r·sin(θ) )
```

An `ArcSegment` stores exactly these parameters — a centre, a radius, a start angle θₛ, and an end angle θₑ — plus a recursion depth.

### The Recursive Rule

Starting from one **root arc** (a quarter-circle, 9 o'clock → 12 o'clock, mimicking the rising back of the wave), `buildFractal` spawns **four children** at fractions *f = 0, ⅓, ⅔, 1* along the parent arc:

| Step              | Formula                                 | Meaning                                                           |
|-------------------|-----------------------------------------|-------------------------------------------------------------------|
| Spawn point       | `P = center + r·(cos θ_f, sin θ_f)`    | Parametric circle equation at fraction *f*                         |
| Child radius      | `r_child = r / 3`                       | Each generation is one-third the size                             |
| Child start angle | `θ_start = θ_f + δ` (δ = 1°)           | Slight rotation gives the curling effect                           |
| Child end angle   | `θ_end = θ_start + span`               | Same angular span → same shape, smaller                            |
| Child centre      | `cx = px − r_child·cos(θ_start)`       | Back-calculated so the child arc starts exactly at the spawn point |
|                   | `cy = py − r_child·sin(θ_start)`       | Same back-calculation for the y-coordinate                         |

The **1/3 scaling** is the key fractal ratio. After *n* levels of recursion, the smallest arcs have radius `r₀ / 3ⁿ`. The total arc count grows as 4ⁿ (four children per arc), so the structure rapidly fills space with finer and finer curves — exactly like the foam at the crest of Hokusai's wave.
